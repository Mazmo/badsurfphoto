# badsurfphoto.com

Site estático da BAD SURF PHOTO, publicado no Cloudflare Pages (projeto `badsurfphoto`).

- Conteúdo capturado do site em produção em 2026-11-24 (113 ficheiros, 76 páginas do sitemap, PT e EN).
- `_headers` e `_redirects` vieram da pasta de deploy de 2026-09-16 no Google Drive (BSP - Site).
- `assets/fonts/space-punk-bold.ttf` é a Space Punk Bold com letras acentuadas (versão 1.1, 2026-11-24); o original de 2013 não tinha acentos.

Publicar: `npx wrangler pages deploy . --project-name badsurfphoto` ou ligar este repositório ao projeto no painel do Cloudflare Pages.
